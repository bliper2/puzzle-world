# Puzzle World

A fancy dark-themed puzzle website featuring Arabic and English name guessing games with an AI-powered puzzle engine.

## Features

- 🎮 Arabic Name Puzzle - Guess scrambled Arabic names
- 🎮 English Name Puzzle - Unscramble and guess English names  
- 🤖 AI Puzzle Engine - Dynamic riddles, patterns, math, logic, and wordplay puzzles
- 📱 Responsive design optimized for Smart TV, mobile, and desktop
- 🏆 Leaderboard with localStorage persistence
- ✨ Fancy dark theme with animations and glow effects

## Technologies

- HTML5, CSS3, Vanilla JavaScript
- AI puzzle generation engine
- LocalStorage for scores and leaderboard

## Deploy to Vercel

1. Push code to GitHub
2. Go to [Vercel](https://vercel.com/new)
3. Import your `puzzle-world` repository
4. Click "Deploy"

## Play Locally

Open `index.html` in any modern browser.
